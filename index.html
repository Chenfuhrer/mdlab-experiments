实验目录

每个实验都有四页：实验台、原理讲解、数据表、易错点与思考题。

实验台怎么用

  1. 接探头选上方的 CH1 / CH2 / 万用表，再点原理图上的节点。示波器和万用表立即显示该点的电压。
  2. 拧旋钮拖动右侧滑块改信号源幅度、频率和元件值；“预设”按钮对应教案中的每一张图。
  3. 读仪器示波器自动给出峰峰值、频率、增益、相位差和 THD；扫频仪给出幅频特性和截止频率。
  4. 填表格数据表页一键仿真测量，悬停可看 ngspice 参考值；打开“录入我的实测”填实验室数据，自动算偏差、导出 CSV。

仿真结果可信吗？

实验台背后是一个手写的电路仿真引擎（改进节点分析法 + Newton 迭代 + Gear-2 积分），跑在你的浏览器里，不依赖任何服务器。 器件用的是 2N5551 的 Gummel-Poon 模型和按数据手册标定的 LM358 宏模型，与离线 ngspice-47 网表完全相同。下表是两者逐项对照。

复现方法：在仓库目录运行 node tools/validate.js --full（需 Node.js ≥ 18），与 data/reference.json 中的 ngspice 结果对比。 模型局限：BJT 未计入结电容（只影响 MHz 级高频），LM358 宏模型不含交越失真；这些对本课程的测试频率没有影响，但实测与仿真之间的偏差主要会来自器件参数的离散性（例如 β）。
